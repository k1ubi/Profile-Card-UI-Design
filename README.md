Glassmorphic profile card UI component — pure HTML, CSS, and JavaScript. No
framework, no dependencies. Drop it into any project or use as a standalone
demo page.

<br>

```
▓▒░ 0x01 // FEATURES ░▒▓
```


- frosted-glass background with `backdrop-filter: blur`
- hover animations and smooth transitions
- social link icons
- responsive layout

<br>

```
▓▒░ 0x02 // USAGE ░▒▓
```


Open `index.html` directly in a browser or serve with any static server:

```bash
git clone https://github.com/k1ubi/Profile-Card-UI-Design.git
cd Profile-Card-UI-Design
python3 -m http.server 8080
# → http://localhost:8080
```
